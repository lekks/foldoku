Квадригами

Генератор новых листов. Лист 8×8 нужно сложить по линиям сетки и диагоналям клеток в квадрат 4×4: одна сторона полностью чёрная, другая полностью белая. Каждое задание получено честным складыванием, поэтому решение есть всегда.

Цвет листа

Решение

долина: перегнуть поверх гора: подогнуть под низ
Решение скрыто, чтобы не подсматривать. На схемах видна верхняя сторона стопки; бледным показана часть, которую сгибаем.

    Сгибы делаются по всей толщине стопки сразу, и часть, которая не двигается, остаётся на месте. Ложные клетки — это чёрные и белые грани, которые в итоге оказываются спрятаны внутри квадрата. Чтобы распечатать лист, откройте файл index.html из папки проекта в браузере и печатайте на двух сторонах с переворотом по длинному краю.
